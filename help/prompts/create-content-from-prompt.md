For admins and managers, each row in **Tracked Prompts** has a **…** menu with **Create content** and **Improve position…**. Use them to start a page written for the prompt, or to improve a page of yours that AI engines already cite.

## Start a page with Create content

1. Click **Create content**. It opens **New content** at its Start step, titled with the prompt.
2. Pick a page type. GetCito picks one from the title; change it if it's wrong, now or later in the editor.
3. Choose **Who does it**: **Me** opens the Content Editor, **Agent** writes a draft for you to review, and **Team** sends it to the Action Center.
4. Check the overlap. Start reads your pages AI already cites for the prompt. If one already answers it, you can optimize that page instead of choosing **Create a new page**.

## When a draft already exists

If a draft that isn't published yet already covers the prompt, one started from the prompt, its topic or an opportunity, the menu shows **Open draft** instead. That way you don't start a second page for the same prompt.

## The content step in Improve

**Improve position…** opens the prompt's positions panel. Its **Improve** tab starts with a content step, decided from the answers in the panel's period:

- No answer mentions or cites your brand: **Create content**, to start a new page.
- Your brand is named in under 20% of the answers, with 5 or more answers: **Optimize content**.
- Your average position is worse than #3, over 3 or more answers that name you: **Optimize content**.
- Anything else: no content step.

**Optimize content** opens Start on your page AI engines cite most for the prompt. When none is cited, Start lists your pages that answer the prompt so you can pick one. When a draft already covers the prompt, the step offers **Open draft**.

## How Improve's suggestions are written

The **Improve** tab's suggestions per platform are written from the answers' evidence and from this brand's last two Improve actions on the prompt for the same region: which of their suggestions were done or skipped, and how each platform moved since. They build on what moved, and don't suggest again what was done on a platform that didn't move, or what your team skipped. An action sent less than a week ago is too early to tell either way.

## Suggestions that use competitor pages

When the Action Center's **Compare competitor content and coverage** task has read pages cited for the prompt in the last four weeks, the **Improve** tab's suggestions also see what Site Audit's checks found on them: which checks each competitor page passes, and which they pass that your cited page doesn't.
